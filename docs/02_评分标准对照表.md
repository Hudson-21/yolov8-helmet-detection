## 建议的执行顺序

```bash
# 第 1 天：采集（预计 2~3 小时拍 1000 张）
python src/collect_images.py --name site_a_1023 --interval 1.0
python src/collect_images.py --name site_b_1023 --interval 1.0
# 第 2~3 天：labelImg 标注（1000 张约 6~10 小时，可分批）
# 第 4 天：清洗划分 + 复核 + 训练
python src/split_dataset.py --resize 640
python src/check_labels.py
python src/train.py --model cbam --name exp_cbam --hyp configs/hyp_tuned.yaml
# 第 5 天：评估 + 消融对比（写文档用）
python src/val.py --split val
python src/train.py --model baseline --name exp_base   # 基线对照
python src/val.py --weights weights/trained/exp_cbam_best.pt weights/trained/exp_base_best.pt
# 第 6 天：演示录屏 + 文档
python src/ui_app.py
```
